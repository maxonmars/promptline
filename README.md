# promptline

CLI на TypeScript для диалога с LLM через DeepSeek API прямо в терминале.

## Как это работает

DeepSeek предоставляет API, совместимый с форматом OpenAI. Поэтому используется официальный пакет `openai`, у которого достаточно подменить `baseURL` на `https://api.deepseek.com`. Вся логика — в одном файле `src/index.ts`.

История диалога хранится в памяти процесса и отправляется целиком с каждым вопросом — значит, чем длиннее разговор, тем дороже каждая следующая реплика. При выходе история теряется.

## Запуск

Нужен Node.js 20 или новее.

```bash
# 1. Установить зависимости
npm install

# 2. Создать .env из шаблона и вписать свой ключ
cp .env.example .env

# 3. Запустить
npm run dev
```

Ключ можно получить на https://platform.deepseek.com/api_keys — для запросов нужен положительный баланс.

## Использование

Без аргументов запускается диалог: вопрос — ответ — снова вопрос. Модель видит всю
предыдущую переписку, поэтому можно уточнять («а короче?», «приведи пример»).
Выход — «выход», Ctrl+C или Ctrl+D.

```bash
npm run dev
```

С аргументом — один вопрос, один ответ, выход:

```bash
npm run dev -- "Объясни, что такое REST API, в трёх предложениях"
```

## Пример вывода

```
Модель: deepseek-v4-flash. Выход — «выход», Ctrl+C или Ctrl+D.

> Что такое REST API?

REST API — это способ общения между программами через обычные HTTP-запросы.
Клиент отправляет запрос на определённый адрес, сервер возвращает данные,
обычно в формате JSON.

> А в одном предложении?

Это набор правил, по которым программы обмениваются данными через HTTP.

> выход

— израсходовано токенов за сессию: 164
```

## Модели

| Модель | Когда использовать |
| --- | --- |
| `deepseek-v4-flash` | по умолчанию, быстрая и дешёвая |
| `deepseek-v4-pro` | сложные задачи, дороже |

Поменять можно через переменную `DEEPSEEK_MODEL` в `.env`.

## Структура

```
src/index.ts     весь код
.env.example     шаблон конфигурации
.env             ваш ключ, в git не попадает
```

## Про безопасность ключа

Ключ лежит только в `.env`, который добавлен в `.gitignore`. В репозиторий коммитится `.env.example` с пустым значением. Если ключ случайно попал в коммит — его нужно отозвать в панели DeepSeek и выпустить новый: переписывание истории git не помогает, публичные репозитории сканируются ботами в реальном времени.
